\# Number Guessing Game



\## Description

A Python GUI-based Number Guessing Game built using Tkinter.



\## Features

\- Voice feedback using pyttsx3

\- Multiple difficulty levels

\- Hint system

\- Light/Dark theme

\- Score tracking

\- Player statistics



\## Technologies Used

\- Python

\- Tkinter

\- pyttsx3
